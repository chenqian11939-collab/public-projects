# 付款助手

付款助手是一款原生 Windows 工具，用于按厂家清单依次显示收款二维码，并记录付款进度。

[下载 Windows 便携版](https://github.com/chenqian11939-collab/public-projects/releases/tag/payment-assistant-2026-11-15)

适用于 Windows 10 和 Windows 11。下载并解压 ZIP，双击 `付款助手.exe`。

1. 点击「二维码文件夹」，选择存放收款二维码图片的文件夹。程序按图片文件名匹配厂家。
2. 从微信或 Excel 粘贴厂家名单，每行一家。点击「匹配并加入清单」，或按 `Ctrl + Enter`。
3. 核对匹配结果。可以更换二维码，也可以将某一项改为微信转账。
4. 点击「开始连续付款」。在手机上完成付款后，按 `Enter` 或点击「已付款，下一家」记录进度。
5. 关闭程序会归档当前清单。可以通过「历史清单」查看明细。

付款记录保存在本机。程序只显示二维码、记录付款状态，转账由使用者在手机上完成。
