顺序贴 1.3.2
本地文本复制、顺序粘贴工具

安装与启动
双击“顺序贴安装包.exe”，选择目录后安装。安装时可创建桌面快捷方式。
本机推荐目录为 J:\顺序贴；其他电脑可以自行选择可写的目录。
程序面向 Windows 10/11，使用 Windows 的 .NET Framework，不需要 Python 或联网账户。
更新前请从托盘菜单退出正在运行的旧版。再次安装到同一目录会保留 Data 中的文本与设置。
请不要同时运行多个版本，以免它们争用同一组快捷键。

默认快捷键（可在“快捷键设置”中修改）
F1：复制选中的文本；勾选“复制时自动加入队列”后会追加到列表。
F2：粘贴下一条，随后移动到下一个位置。
F3：从当前位置开始批量粘贴；再次按下可停止。
F4：粘贴系统剪贴板内容。
Esc：批量操作期间停止。切换到其他窗口也会停止批量操作。
以上按键都可以自定义；升级安装会保留你已保存的自定义组合。

启用与关闭热键
主窗口右上角和托盘菜单都有热键开关，迷你窗口也可以切换。
在“快捷键设置”选好按键后，直接点击“启用热键”或“应用并启用”，会保存并应用当前选择。
设置页显示“尚未应用”时，请按提示修正具体那一项；顶部横条始终显示实际生效的按键。
F1、F2 等功能键可单独使用；字母 V、B 等必须勾选 Ctrl 或 Alt，不能全部取消。
也可点“填入 F1–F4 方案”：F1 复制、F2 顺序粘贴、F3 批量、F4 粘贴当前剪贴板，再启用。
启用后，F1 等已设置的键执行本工具的动作。
关闭后，本工具释放这些键并停止当前操作，恢复按键在其他软件中的正常用途。
关闭时保存快捷键设置不会自动启用。程序会记住上次的开关状态。
若提示按键被占用，请先关闭另一份本工具或其他软件的同名热键，或者更换组合。

迷你窗口
主窗口底部点击“迷你窗口”，也可以从托盘菜单打开。
迷你窗口显示“序号 / 文本内容”，红色箭头标出下一次单条顺序粘贴的位置。
顶部显示下次粘贴的序号和总条数。每次复制、粘贴后会自动同步。
双击条目或点击“编辑”可修改完整内容，包括多行文本；鼠标悬停可查看完整内容。
按住条目用鼠标左键上下拖动，放到蓝线位置即可调整顺序，主窗口同步更新。
拖到列表顶部或底部边缘可自动滚动。拖出列表或按 Esc 可取消拖动。
选中后点击“删除”可移除一条；“清空”在确认后同时清空两个窗口，并重置下一条位置。
Ctrl + 上箭头 / Ctrl + 下箭头：在迷你列表中调整所选条目的顺序。
“从选中条目继续粘贴”可直接指定下一条，不会立即把内容输入到其他程序。
调整顺序时，下一条标记跟随原来的文本。删除下一条时，标记移到后面的条目。
“显示 / 收起主窗”便于只保留迷你窗口工作。
可以置顶和移动；拖动窗口边框或右下角缩放手柄可以改变大小，位置和大小会保存。
点击迷你窗口的叉号只隐藏小窗口，本工具仍在托盘运行。
正在执行粘贴时暂时不能编辑队列；编辑对话框打开时也不会启动新的复制粘贴操作。

批量粘贴
单条 F2 粘贴完成后立即接受下一次按键，不再等待批量粘贴间隔。
可选 Tab、回车、无分隔，并可调整间隔和每批条数。0 表示剩余全部条目。
间隔过短时，目标程序可能来不及处理，请适当加大间隔。
回车在聊天和网页里可能触发发送或提交，建议先在记事本或测试表格里确认。
循环选项仅影响单条顺序粘贴。到末尾后若要再次批量操作，请重置或手动指定下一条。

数据与兼容性
文本队列、快捷键及窗口设置保存在安装目录的 Data\settings.json。
自动备份保存在 Data\settings.json.bak。整个 Data 文件夹可用于备份或迁移。
队列是本地明文数据，请根据内容妥善保管。不要把自己的 Data 文件夹发给其他人。
“导出队列 / 导入队列”可以保留多行条目；TXT 导入按非空行拆分。
顺序粘贴会更新系统剪贴板。工具只处理文本，不支持图片或复杂格式。
目标程序需要支持 Ctrl+C / Ctrl+V。目标以管理员身份运行时，本工具通常也需要相同权限。

退出与卸载
点击主窗口右上角 X（或按 Alt+F4）会最小化到托盘，程序和已启用的热键继续运行，迷你窗口保持原状态。
双击托盘图标，或在托盘菜单中选择“打开主窗口”，可以恢复主窗口。
需要彻底关闭时，右键托盘图标并选择“退出”，程序会保存数据并释放热键。
在安装目录运行“卸载顺序贴.exe”可移除程序和它创建的桌面快捷方式。
卸载会保留 Data 数据文件夹，便于重新安装或自行备份。

分发
把“顺序贴安装包.exe”发给其他 Windows 用户即可安装，不需要附带你本机的 Data。
本工具是独立编写的程序，不依赖原软件的文件或授权服务。
