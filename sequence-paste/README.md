# 顺序贴（Sequence Paste）

<img src="src/Assets/app-icon.png" alt="顺序贴图标" width="96">

轻量的 Windows 本地文本复制、顺序粘贴工具，使用 C#、WinForms 和 .NET Framework 开发。

**[下载 1.3.2 完整安装包](https://github.com/chenqian11939-collab/public-projects/releases/tag/sequence-paste-v1.3.2)**

面向 Windows 10/11。双击安装包，选择可写的独立目录安装。无需 Python、登录账号或联网服务。升级前从托盘菜单退出旧版本；安装到原目录会保留 `Data` 中的文本和设置。

## 主要功能

- 自定义复制、粘贴、下一条及批量操作的全局快捷键。
- 热键开关：启用时使用软件快捷键，关闭后释放按键。
- 复制文本加入队列，按顺序逐条或批量粘贴。
- 迷你窗口显示已复制内容与下一条位置，支持拖动排序、编辑、删除、清空及调整大小；与主窗口同步。
- 点击主窗口 X 最小化到托盘；双击托盘恢复，右键选择“退出”彻底关闭。
- 文本队列、顺序和设置保存在本机，支持导入、导出。

## 默认快捷键

| 按键 | 功能 |
| --- | --- |
| F1 | 复制选中文本；启用自动加入队列后追加到列表 |
| F2 | 粘贴下一条 |
| F3 | 批量开始 / 停止 |
| F4 | 粘贴当前系统剪贴板 |
| Esc | 停止进行中的批量粘贴 |

F1–F4 可以自定义。首次使用前点击“启用热键”。目标程序需支持 Ctrl+C / Ctrl+V；本工具处理纯文本。

## 从源码构建

在 Windows PowerShell 中执行：

```powershell
.\src\build-installer.ps1
```

脚本使用系统 .NET Framework C# 编译器，无第三方 NuGet 依赖。`src/build.ps1` 仅构建主程序。编译输出统一写入 `dist/`：

- `顺序贴.exe`
- `顺序贴安装包.exe`
- `卸载顺序贴.exe`
- `顺序贴.ico`
- `使用说明.txt`
